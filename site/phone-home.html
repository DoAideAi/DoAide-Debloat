How it is measured

  • PCAPdroid, an open-source app that needs no root, records the phone's traffic for ten idle minutes. The lock screen is woken ten times, the way a person glances at a phone.
  • Server names come from DNS, the TLS server name and the HTTP Host header. Nothing is decrypted.
  • A server counts as ad or tracking when one of HaGeZi's lists names it: the phone makers' own telemetry, and the broad Pro list. Exodus Privacy supplies the company names.
  • Counts vary from run to run with the network, the time of day and app updates. A row with one report is one phone on one evening.
  • Reports are filed by their owners as public GitHub issues and hold counts, plus the tracker domains and package names of preinstalled apps. Never serial numbers, IP addresses or the owner's own apps.
